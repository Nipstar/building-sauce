# buildingsauce.com

Marketing site for Building Sauce, a weekly lead feed for contractors built from public NYC records. Run by Antek Automation.

- `npm run dev` to work on it, `npm run check` before deploy.
- Read `HANDOVER.md` for how pages, facts, guides, data and forms fit together.
- Spec: `docs/spec/`. Plan: `docs/superpowers/plans/`.

Never commit `.env`, lead data, building lists or anything from the feed itself. Public pages show aggregates only.
